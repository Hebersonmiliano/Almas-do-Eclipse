# Regras deste projeto

- Toda alteração segue primeiro para a branch `teste`.
- Não enviar, mesclar ou publicar alterações em `main`/produção sem confirmação explícita do usuário referente à versão testada.
- Não habilitar auto-merge ou deploy automático de produção.
- Antes de propor promoção, identificar o commit testado e relatar verificações e limitações.
- Rodar `npm test` e `npm run build` antes de enviar a branch de teste.
- Preservar mecânicas existentes; corrigir em etapas.
